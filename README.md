# 3D-5D_Slicer_STE

Решение кейса Росатом / Stereotech на хакатоне «Открой#Моспром»: плагин **AI Assistant** для STE Slicer.
Это чат-бот на базе LLM, который подбирает режим печати 3D/5D, материал, профиль и настройки, ориентирует модель,
запускает слайсинг и объясняет свои решения. Инструменты слайсера доступны боту через встроенный MCP-сервер.

## Структура (по требованиям сдачи)

```
plugin/                      исходный код плагина + README (установка, настройка URL и ключа LLM)
results/<модель>/
    project.3mf              проект, полученный через чатбот
    result.gcode             G-code — результат слайсинга (хранится в Git LFS)
    chat_*.png               скриншоты переписки в чатботе
    passport.md, .json       паспорт рецепта: решения с обоснованием, предпечатная проверка,
                             разбор 5D-советника, изменённые настройки, SHA-256 файлов
```

Установка, настройка и архитектура описаны в [plugin/README.md](plugin/README.md).
G-code лежит в Git LFS: для скачивания клонируйте с установленным `git lfs` или скачайте файлы на GitHub.

## Результаты по 7 эталонным деталям

Все детали подготовлены через чат текущей версией плагина (LLM qwen3.8-flash, режим «Инженер»).
Режим совпал с эталоном кейса у всех семи; время и масса — расчёт движка слайсера.

| Папка | Деталь | Режим | Материал | Печать | Масса |
|---|---|---|---|---|---|
| `01_gear` | Шестерня | 3D | Enduse PC | 1 ч 07 мин | 4,6 г |
| `02_conveyor_wheel` | Колесо конвейера | 5D, база ⌀15,9 мм | Enduse TPU D70 | 5 ч 35 мин | 29,2 г |
| `03_cv_boot` | Пыльник ШРУСа | 3D | Sealant TPV80 | 39 ч 57 мин | 79,7 г |
| `04_figurine` | Фигурка | 3D | Enduse PETG | 98 ч 23 мин | 362,5 г |
| `05_pump_impeller` | Рабочее колесо насоса | 5D, база ⌀7,9 мм | Fiberpart PP G30 | 36 ч 42 мин | 143,9 г |
| `06_fan_impeller` | Крыльчатка охлаждения | 3D | Fiberpart PP G30 | 12 ч 51 мин | 62,8 г |
| `07_krones_axis` | Ось Krones | 5D, база ⌀10 мм | Enduse PA6 | 5 ч 50 мин | 10,4 г |

Обоснование каждого решения — в `passport.md` и на скриншоте переписки. В итоговом тексте чата модель
иногда ошибается в цифрах; верные время и масса — на карточке результата нарезки и в паспорте.

## Как работаем

1. Перед началом работы: `git pull`.
2. После готового кусочка: `git add -A`, `git commit -m "что сделал"`, `git push`.
3. Один файл одновременно правит один человек.
4. Ключ LLM никогда не кладём в файлы проекта: плагин хранит его в настройках слайсера.
