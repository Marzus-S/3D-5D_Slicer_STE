# AI Assistant — плагин-ассистент для STE Slicer

Чат-бот на базе LLM внутри STE Slicer 7.x. Пользователь описывает задачу (или вставляет ТЗ на деталь),
прикладывает STL/OBJ/3MF и фото, а ассистент сам:

1. загружает модель и проверяет файл до печати: единицы (дюймы вместо мм), дыры в сетке, отдельные тела,
   тонкие стенки, малые отверстия, рабочая область и масса;
2. анализирует геометрию и выбирает режим печати — 3D (`classic`), 5D Spiral (`cylindrical`) или 5D
   (`cylindrical_full`) — по баллам 5D-советника с объяснением каждого балла и диаметром базы;
3. подбирает материал Stereotech по требованиям задачи, профиль качества и ключевые настройки;
4. ориентирует и расставляет модель (для 5D — осью вертикально по центру стола);
5. запускает слайсинг, сохраняет G-code, проект 3MF и паспорт рецепта;
6. объясняет каждое решение.

Все действия агента видны в чате как карточки вызовов инструментов с аргументами и результатами.

## Установка

1. Установите STE Slicer 7.10.12 и активируйте лицензию: начните нарезку в 5D → окно ATSS → код → форма на
   странице хакатона → запустите полученный `steslicer_license.reg` → перезапустите слайсер.
2. Скопируйте папку `AIAssistant` в папку плагинов:
   `%APPDATA%\steslicer\7.x\plugins\AIAssistant`
   (папка конфигурации открывается через **Справка → Показать папку конфигурации**, внутри — `plugins`).
3. Перезапустите слайсер. В меню **Расширения** появится пункт **AI Assistant**.

Внешних зависимостей нет: только стандартная библиотека Python 3.5, PyQt5 и numpy из дистрибутива слайсера.

## Настройка URL и ключа LLM

1. **Расширения → AI Assistant → Открыть чат** — чат откроется в системном браузере.
2. Нажмите **Настройки** и укажите:
   - **URL API** — адрес OpenAI-совместимого API, выданный организаторами (например `https://…/v1`);
   - **Ключ API**;
   - **Модель** — можно оставить пустым: возьмётся первая из `/models`;
   - **Папка результатов** — по умолчанию `Документы\STE_AI_results`.
3. **Проверить подключение** → **Сохранить**.

Ключ хранится в настройках приложения STE Slicer (`aiassistant/api_key`), в коде не захардкожен
и обратно в браузер не отдаётся: API настроек сообщает только, сохранён ли ключ.

## Использование

- Напишите задачу, например «Кронштейн под нагрузку, PETG, без поддержек», и прикрепите STL
  (кнопка-скрепка или перетаскивание в окно). Можно приложить фото детали.
- Ассистент выполнит весь цикл и ответит итогом по шаблону: режим, материал, профиль, ключевые настройки,
  ориентация, время печати и расход материала, пути к файлам, рекомендации.
- Можно продолжать диалог: «сделай заполнение 60 % и перенарежь», «сравни профили по времени».
- **Новый диалог** очищает историю, **Стоп** прерывает агента.

### Режимы чата

Переключатель в шапке — лестница от ученика до профессионала:

| Режим | Для кого | Как ведёт себя ассистент |
|---|---|---|
| Обучение | хочет научиться сам | наставник: показывает факты и спрашивает «что бы выбрали вы?», разбирает ваши настройки (`review_my_settings`), после нарезки задаёт квиз |
| Новичок | только начинает | простые слова, пара уточняющих вопросов, решает сам |
| Инженер | технолог | кратко и технически, без лишних вопросов |
| Профи | важна скорость | ответ таблицей, рецепты вместо подбора, подсказки быстрых команд |

Каждый режим видит свой набор инструментов (`modes` в `register_tools`): квиз не нужен профи, рецепты — ученику.

### Быстрые команды

Строка, начинающаяся с `/`, выполняется сразу, без нейросети: разбор строки и прямой вызов инструментов.
Список подсказывается при вводе `/` (Tab — дополнить), полный — `/help`.

```
/mode 5d   /mat pa6   /profile fine   /infill 40   /walls 5   /layers 6   /supports off
/set wall_line_count=5 speed_print=40   /orient ось   /slice   /export 01_gear   /save 01_gear
/saverecipe шестерня-PA6   /recipes   /recipe шестерня 01_gear   /check loaded   /quiz материал
/analyze кручение   /analyze качение гибкая   /passport 01_gear   /matinfo pa6
```

Справочник материалов «как напечатано» (`agent/materials.py`): прочность вдоль и поперёк слоёв, рабочая
температура и сушка для ABS, ASA, PLA, PETG, PA, TPU, PC и PP. У каждого числа метка источника: печатные образцы
из руководства Hybrid 530, режимы сушки QIDI, ORNL или оценка. Чат отвечает по нему инструментом `material_info`,
`/check` напоминает о сушке гигроскопичных материалов.

Рецепт сохраняет режим, материал, профиль, ориентацию и изменённые настройки; `/recipe` применяет его как
`apply_plan` (сброс, настройки, нарезка, G-code и 3MF). Рецепты, прогресс квизов и история чатов лежат
в папке данных слайсера: `aiassistant_recipes.json`, `aiassistant_progress.json`, `aiassistant_chats/`.

Результаты сохраняются по шаблону сдачи:

```
<папка результатов>/<имя модели>/result.gcode
<папка результатов>/<имя модели>/project.3mf
<папка результатов>/<имя модели>/passport.md     паспорт рецепта для технолога
<папка результатов>/<имя модели>/passport.json   то же для программ (формат ste-ai-recipe/1)
```

Паспорт рецепта фиксирует, что и как напечатано, чтобы деталь можно было повторить на другом принтере и
проверить решение: задача, режим, материал, профиль и ориентация с обоснованием, все изменённые настройки с
причиной, предпечатная проверка, разбор 5D-советника, время и масса, результат проверки G-code, SHA-256 модели,
G-code и 3MF, версии слайсера, плагина и LLM. Статус паспорта — «черновик — требует проверки технологом»;
поля для партии материала, сушки, утверждения и результата печати технолог заполняет сам.

## Архитектура

```
Браузер: SPA (web/index.html, app.js, style.css)
   │  fetch + polling, http://127.0.0.1:<порт> (по умолчанию 8765)
   ▼
Плагин в STE Slicer (Python 3.5)
   ├─ AIAssistant.py      — пункт меню, запуск сервера, настройки
   ├─ agent/server.py     — HTTP-сервер: статика, /api/*, /mcp
   ├─ agent/agent.py      — цикл диалога с LLM, вложения, лента событий
   ├─ agent/mcp.py        — MCP-сервер: JSON-RPC 2.0 (initialize, ping, tools/list, tools/call)
   ├─ agent/registry.py   — реестр инструментов: одна схема и для MCP, и для LLM
   ├─ agent/tools.py      — инструменты над API слайсера (через главный поток Qt)
   ├─ agent/geometry.py   — анализ геометрии на numpy: нависания, тело вращения, сетка, толщина стенок
   ├─ agent/advisor.py    — предпечатная проверка и 5D-советник (баллы 3D/5D, диаметр базы)
   ├─ agent/passport.py   — паспорт рецепта (passport.md и passport.json)
   ├─ agent/knowledge.py  — инструкция агента, паспорт принтера, лимиты материалов
   ├─ agent/learning.py   — банк вопросов квиза, правила разбора настроек ученика, прогресс
   ├─ agent/recipes.py    — хранилище рецептов
   ├─ agent/materials.py  — справочник материалов «как напечатано» с источниками
   ├─ agent/commands.py   — быстрые команды «/…» без LLM
   ├─ agent/llm.py        — клиент OpenAI-совместимого API (Chat Completions + tool calling)
   └─ agent/mainthread.py — безопасный вызов кода в главном потоке (callLater + ожидание)
   ▼
OpenAI-совместимый API LLM            API STE Slicer (настройки, профили, сцена, слайсинг)
```

Встроенный агент вызывает инструменты не напрямую, а через тот же MCP-обработчик (`tools/call`),
что доступен снаружи по `/mcp`. LLM получает тот же список инструментов в поле `tools`.

## Инструменты (MCP и LLM)

| Группа | Инструменты |
|---|---|
| Состояние | `get_printer_state` |
| Профили и материалы | `list_quality_profiles`, `set_quality_profile`, `list_materials`, `material_info`, `set_material`, `save_profile` |
| Режим | `set_printing_mode` (`classic` / `cylindrical` / `cylindrical_full`) |
| Настройки | `search_settings`, `get_settings`, `set_settings`, `reset_settings` |
| Модели | `load_model`, `list_objects`, `analyze_model`, `orient_model`, `rotate_model`, `move_model`, `scale_model`, `arrange_all`, `delete_model` |
| Слайсинг | `slice`, `get_slice_status`, `get_slice_result`, `export_gcode`, `validate_gcode`, `save_project`, `compare_variants` |
| Конвейер и паспорт | `apply_plan`, `save_passport` |
| Рецепты | `save_recipe`, `list_recipes`, `apply_recipe` |
| Обучение | `review_my_settings`, `quiz` |

Свои функции поверх минимального набора:

- `analyze_model` — предпечатная проверка и 5D-советник поверх анализа геометрии:
  - проверка: габарит < 5 мм → подозрение на дюймы или сантиметры с готовым `scale_model`; открытые и лишние рёбра,
    число тел, вывернутые нормали; толщина стенок лучами изнутри (меньше двух периметров, меньше ребра 0,4 мм);
    отверстие меньше 2 мм и поле допуска IT12 для посадок; область 3D 300×300×300 мм и масса до 3 кг;
  - 5D-советник складывает баллы с объяснением: тело вращения или выраженная ось, L/D, доля объёма вне базы,
    поддержки, которые в 3D встанут на саму деталь (каналы колёс), грани, смотрящие к оси в 5D, сквозное
    отверстие, нагрузка из задачи (`load`: кручение, давление, качение — за 5D; изгиб зубьев, центробежная — против).
    Запреты: нет оси, гибкий материал, больше 5D-области ⌀300×230 мм или 1,5 кг. Выдаёт вердикт `5d` / `3d` /
    `either`, диаметр базы (по отверстию или 20 % диаметра, 6–10 мм), обороты оси C у базы и диапазон выигрыша
    с источником. На семи тестовых деталях кейса вердикт совпадает с эталоном;
- `orient_model` — автоповорот: минимум поддержек, максимум площади на столе или ось вертикально по центру (для 5D);
- `compare_variants` — нарезка нескольких вариантов настроек и сравнение по времени и расходу материала;
- `export_gcode` — после сохранения проверяет G-code: команды движения, слои, нагрев;
- `apply_plan` — весь план одним вызовом: режим, материал, профиль, ориентация, настройки, нарезка, G-code, 3MF
  и паспорт рецепта с обоснованиями из `rationale`; `save_passport` обновляет паспорт после ручных правок.

### Пример обращения к MCP

Адрес и токен: **Расширения → AI Assistant → Адрес MCP-сервера**. Токен меняется при каждом запуске слайсера.

```bash
curl -s http://127.0.0.1:8765/mcp -H "Authorization: Bearer <токен>" -H "Content-Type: application/json" -d "{\"jsonrpc\":\"2.0\",\"id\":1,\"method\":\"tools/list\"}"
```

## Безопасность

- Сервер слушает только `127.0.0.1`.
- Все `/api/*` и `/mcp` требуют токен сессии (случайные 128 бит, генерируются при запуске). В чат токен
  передаётся во фрагменте URL (`#token=…`), поэтому не попадает в логи и Referer.
- Проверка заголовков `Host` и `Origin` защищает от обращений со сторонних сайтов (CSRF, DNS rebinding).
- Вложения: разрешены только STL/OBJ/3MF/JPG/PNG, ограничение размера, безопасные имена файлов.
- Ключ API не логируется и не возвращается через API.

## Отладка

- Логи слайсера: `stderr.log` и `*.log` в папке конфигурации. Сообщения плагина начинаются с `[AIAssistant]`.
- Если порт 8765 занят, сервер займёт следующий свободный (до 8784).
- Ошибки LLM (неверный ключ, URL, SSL) показываются прямо в чате. Если не проходит проверка сертификата
  внутреннего сервера, её можно отключить в настройках.

## Известные ограничения

- Правила выбора режима и материала заданы в `agent/knowledge.py` как эвристики. Их стоит уточнять по
  результатам прогонов тестовых моделей и ответам экспертов.
- Слайсинг в 5D требует активированной лицензии STE Slicer.
